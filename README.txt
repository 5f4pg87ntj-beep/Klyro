# Klyro prototype
Open `index.html` in a browser.

This is a frontend prototype. It includes:
- Dark space UI with distant stars and planet artwork
- Accent color settings
- Game library with categories and search
- Chat UI
- AI chat demo
- Friends page
- Admin moderation UI
- Responsive layout

The games, chat, AI, accounts, moderation actions and security are demo UI only. A real deployment needs a backend, database, authentication, real game implementations and server-side moderation/security.
